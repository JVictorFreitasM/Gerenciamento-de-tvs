## ⚠️ Arquivo com conteúdo errado

`Tv gerenciamento de midia.jpg` nesta pasta é, na verdade, uma captura do
**Dashboard do Contracheque Bot** (sidebar mostra "Contracheques", "Upload",
"Lotes", "Pendentes"...), não a tela de gestão de mídia do TV Signage.
Provavelmente copiada para a pasta errada — substituir por uma captura real
de `/midia/:setor` (ou mover pra `contracheque-bot/screenshots/`, que já
tem `contracheque dash.jpg` — conferir se não é duplicata antes).
